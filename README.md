# Информационная система «Электронный дневник» (Версия 2.0)

Настольное приложение для общеобразовательных учреждений и учебных заведений СПО, предназначенное для автоматизации учета успеваемости, ведения классного журнала и статистического анализа учебного процесса.

---

## 📌 Описание системы
Программа представляет собой вторую версию информационной системы **«Электронный дневник»** с локальной базой данных **Microsoft Access (`.accdb`)** и модулем авторизации пользователей с разграничением прав доступа. 

В версии 2.0 реализован полноценный **матричный классный журнал**:
* **Для преподавателей и администраторов:** выбор класса и учебного предмета; отображение журнала в виде матрицы (учащиеся по строкам, даты уроков по столбцам); возможность добавления и удаления дат занятий; быстрый ввод и редактирование оценок прямо в ячейках (2–5, Del для очистки) или через контекстное меню; расчет среднего балла ученика и класса.
* **Для учащихся:** просмотр классного журнала своей группы по всем предметам в строгом режиме «Только чтение» (без возможности редактирования) с визуальным выделением собственной строки.

## 🛠 Технологический стек
* **Среда разработки:** Microsoft Visual Studio (2022 / 2026)
* **Язык программирования:** C#
* **Платформа:** Windows Forms (.NET 8.0-windows / .NET Desktop)
* **СУБД:** Microsoft Access (`SchoolDiary.accdb`)
* **Провайдер данных:** Microsoft Access Database Engine OLE DB (`Microsoft.ACE.OLEDB.12.0` / `16.0`) через пакет `System.Data.OleDb`

## 🚀 Функциональные возможности версии 2.0

1. **Модуль авторизации:**
   * Проверка подлинности пользователей по базе данных Access.
   * Безопасный ввод пароля (маскирование).
   * Автоматическая настройка рабочего места под роль (Администратор, Учитель, Ученик).

2. **Матричный классный журнал:**
   * Раздельный выбор учебного класса (`Класс`) и дисциплины (`Предмет`).
   * Классический формат школьного классного журнала: ФИО учащихся по вертикали, календарные даты уроков по горизонтали, оценки на пересечении.
   * Автоматический расчет среднего балла по каждому учащемуся и среднего балла всей группы.
   * Инструменты учителя: кнопки «+ Добавить дату» и «Удалить дату», контекстное меню для быстрой простановки оценок и комментариев.
   * Интерактивный ввод оценок с клавиатуры (клавиши `2`, `3`, `4`, `5` и `Delete` для удаления).
   * Защита от модификации для учащихся: интерфейс заблокирован от редактирования.

3. **Реестр учащихся:**
   * Картотека учащихся учебного заведения.
   * Мгновенный поиск по фамилии и фильтрация по группам.
   * Добавление, редактирование и удаление записей.

## 💻 Запуск и отладка в Visual Studio

1. Откройте файл **`SchoolDiary/SchoolDiary.sln`** в Visual Studio.
2. Выберите конфигурацию **`Debug | x64`** (или `Any CPU`).
3. Нажмите клавишу **`F5`** для запуска.
